# 控制台空间与夜间阅读调整

## 控制台

- 移除“设备工作区”副标题和常驻说明，标题与操作收进约 40 px 的单行栏，工具栏也减少上下留白。
- 只有一个设备时不再显示重复的设备页签；多个设备仍保留页签切换。
- 快捷指令面板可收起，状态会持久化。面板使用隐藏而非卸载，避免中断正在进行的操作或丢失编辑状态。
- 面板宽度根据实际窗口空间收敛，给 AT 主终端预留宽度；双口模式下不再由两个固定宽度面板挤占主终端。
- 日志长行与注释可换行。指令说明限制高度并允许滚动，发送区保持可见。
- RX/TX 计数标为总量，提示它们统计的是软件运行期间所有端口的累计流量。

## 配色与输入

- 夜间背景由近黑改为分层蓝灰，面板、弹层和输入框统一配色。
- 调整链接、主按钮、状态色、时间戳与注释颜色；日志口正文使用正常终端文字色。
- 浅色主题仍保留深色终端；主题偏好不变。
- 串口与 AI 输入框在中文输入法组合输入期间忽略回车发送，确认候选字不会意外提交内容。

## 验证

前端回归检查扩展到 39 项，覆盖输入法回车与既有请求、设备及诊断行为。
实际 Windows 桌面检查补充快捷面板隐藏状态跨重载保留，以及隐藏后指令仍可恢复。
模拟设备检查补充 1028×749 窗口下的标题高度、终端高度、收起面板后的可用宽度、双串口列宽，以及实际渲染颜色的文字对比。

模拟数据仅验证交互和布局；4 项真实串口硬件测试仍需设备完成。
