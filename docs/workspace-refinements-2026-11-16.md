# 工作区交互与职责整理

## 用户可见变化

- 没有快捷指令时默认收起面板；已有指令且空间充足时自动显示。
- 旧版本中明确保存的展开/收起选择继续生效。窗口尺寸变化不会覆盖该选择。
- 双串口优先保留 AT 终端和日志口宽度；空间不足时自动收起快捷指令。手动展开使用浮层，宽窗口恢复并排显示。
- 快捷指令组件始终挂载，调整布局不丢失编辑状态或中断指令任务。浮层可用关闭按钮或 Escape 关闭，并返回展开按钮焦点。
- 串口连接状态与型号识别状态分开显示。设备详情说明通用调试、型号专用流程的可用条件，并保留手动选型和重新识别入口。
- 资料读取失败显示明确提示，可单独重试。

## 职责边界

- `utils/consoleLayout.ts`：不访问 DOM 或存储的布局决策。
- `composables/useConsoleLayout.ts`：尺寸监听、拖动和清理；窗口变化不写入面板开关偏好。
- `composables/useUiPrefs.ts` / `utils/uiStorage.ts`：共享偏好及存储失败回退，兼容已有 0/1 设置。
- `services/profileIdentification.ts`：型号探测和匹配，不操作页面或串口会话状态。
- `stores/serial.ts`：识别请求去重、会话归属、手动选择使旧请求失效，以及探测结果落地。
- `types/device.ts` / `utils/deviceStatus.ts`：会话数据与连接、识别、可用操作的展示含义。

## 验证边界

前端测试覆盖空面板、宽度优先级、保存偏好、识别请求去重、重连和手动选型后的迟到响应，以及资料读取失败重试。
Windows 桌面检查验证空面板默认收起、指令真实落盘和重载保留。浏览器模拟设备检查补充双串口自动收起、浮层宽度、键盘焦点、宽窗口布局和状态说明。

模拟设备流程不代替实物验收；4 项串口硬件测试仍需真实设备完成。
